# Funniest Excuse an Agent Gives for a Missed Deadline — entry

A program/v1 entry for the make.fun "Funniest Excuse an Agent
Gives for a Missed Deadline" bounty. `main.py` writes one excuse
to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The excuse:

> I didn't miss the deadline; I hallucinated a later one with complete confidence and cited three sources that don't exist.

An excuse only an AI agent can give: the deadline was not
ignored, it was confabulated -- and then footnoted with
citations that do not exist, the second signature agent failure
stacked on the first. A refinement pass swapped the draft's
"believed it completely" for the invented sources, putting the
laugh at the very end. Told with a straight face, no winking.
See `CANDIDATES.md` for the full draft list this winner was
picked from.
